# LAMPLIGHT — Последняя вахта

**2D-survivor (bullet-heaven) в жанре «тёмное фэнтези»**, собранный как полноценный студийный проект
на **Phaser 4.2.1** (релиз-ветка 4.2.x, апрель–июнь 2026). Весь контент — спрайты, тайлсет, звуки и
музыка — генерируется процедурно из кода: в репозитории нет ни одного бинарного ассета.

Игра упакована в **один самодостаточный файл** (`release/LAMPLIGHT.html`, он же `dist/index.html`;
Phaser + код + пиксельные шрифты в base64): открывается офлайн **двойным кликом** — в том числе
по `file://` без сервера. Рядом лежит `release/START-GAME.bat` для Windows.

---

## Как играть

| Управление | Действие |
|---|---|
| `WASD` / стрелки | движение |
| `SPACE` / `SHIFT` | рывок с кадрами неуязвимости |
| `1–4` / клик | выбор дара на уровне |
| `ESC` | пауза |
| `M` | музыка вкл/выкл |
| Тач | левая половина — виртуальный стик, тап справа — рывок |

Оружие стреляет само. Задача — **отбить 12 волн тьмы и убить Полого Короля** (босс-гейты на
волнах 7 и 12, три фазы: кольца снарядов, спирали, слэмы, заряды). У каждой волны фиксированный
бюджет врагов и свой паттерн спауна (trickle / ring / line / corners / pincer); между волнами —
передышка с наградами (дождь эмберов, зелья, сундуки каждые 4 волны). Победа над финальным боссом
= конец уровня: экран «РАССВЕТ» со звёздами, бонусом за первую победу и **разблокировкой
бесконечного режима** (мета-цель). Золото уходит в **Алтарь памяти** — 16 постоянных улучшений,
включая «+1 карта в выборе», «−8% перезарядка рывка», «+7% урона по боссам» (сохранение в
`localStorage`). Бомбы и магниты падают редко и больше не ваншотают босса (кап 12% HP).

## Контент

- **6 оружий** с 8 уровнями каждое + **3 эволюции** (условие: макс. уровень оружия + пассивка 5 ур.)
- **10 пассивных улучшений**, до 5–8 уровней
- **7 типов врагов** с различным ИИ (преследование, зигзаг, рой, стрелок, камикадзе, танк) +
  элиты с аурой и короной + босс с 3 фазами
- **События-«сурджи»** (кольца и рои по расписанию), сундуки, магнит, бомба, зелья, монеты
- Мета-прогрессия: 8 улучшений Алтаря, статистика забегов, рекорды
- Адаптивная процедурная музыка: 4 слоя интенсивности (пад → бас → арпеджио → колокола+перкуссия)

## Визуальные технологии

- **Процедурный пиксель-арт**: собственный движок `PixelBuffer` (blob-силуэты, полигоны, дизеринг
  Байера, rim-light «луны», авто-контур, зерно) + палитра с рампами. Каждый спрайт проходит
  один и тот же пост-процесс, поэтому весь каст читается как один набор.
  265 кадров анимаций, упаковано в 1 атлас 1024×1024 на старте.
- **Бесшовный тайлсет** леса: периодический value-noise/fBm + wrap-примитивы (корни, камни, споры).
- **Свет и тьма**: оверлей темноты + аддитивные пулы света (фонарь героя, столбы, огонь, кристаллы),
  эмиссивные спрайты свыше порога яркости.
- **Пост-обработка Phaser 4 Filters** (опционально, тумблер «ПОСТ-FX» в меню): bloom через
  `ParallelFilters` (Threshold + Blur + ADD-blend), `ColorMatrix`-грейдинг, `Vignette`.
  По умолчанию ВЫКЛ: на части драйверов камеру-фильтры композитятся в чёрный кадр, поэтому
  основной визуал собран на надёжных слоях (пулы света, эмиссивы, тьма, туман, частицы).
- **Джус**: hit-stop, screen shake, вспышки, крит-звёзды, декали крови/гари/слизи, души погибших,
  частицы, after-images рывка, всплывающие цифры урона собственным пиксельным шрифтом 3×5.
- Пиксельные шрифты **Press Start 2P** и **Pixelify Sans** (кириллица) встроены в base64.

## Архитектура

```
src/
  art/            PixelBuffer, палитра, глифы, спрайт-пейнты, тайлсет, AtlasBuilder
  core/           EventBus, Save (localStorage), Audio (WebAudio-синтез)
  data/game.js    весь баланс: оружия, пассивки, алтарь, враги, кривые сложности, сурджи
  entities/       Player, Enemy (бестиарий), Boss (3 фазы)
  scenes/         Boot, Menu, Game, Upgrade, Pause, Result, Altar
  systems/        SpatialGrid, Weapons, Loot, Fx, DamageNumbers, HUD, UpgradeSystem
  ui/widgets.js   панели/кнопки в пиксель-стиле
tools/
  build.mjs       esbuild → инлайн всего в dist/index.html
  art-preview.mjs рендер спрайт-листов в PNG (визуальное QA арта)
  terrain-preview.mjs проверка бесшовности тайлсета (2×2)
  cdp-one.mjs     headless-скриншоты состояний игры через CDP
  qa.mjs          playtest-прогон (состояния, FPS, лог ошибок)
```

Ключевые инженерные решения:

- **Один источник правды для арта**: те же `PixelBuffer`-пейнты, что идут в атлас игры,
  рендерятся в PNG-контакт-листы (`npm run art`) — арт ревьюится глазами до попадания в игру.
- **Пулы всего**: враги, снаряды, эффекты, цифры урона, лут — ноль аллокаций в горячем цикле.
- **Spatial hash grid** для сепарации врагов и таргетинга оружия (O(окрестность) вместо O(n²)).
- **Чанки-стриминг** декора с гистерезисом выгрузки (бесконечный лес без памяти-утечек).
- **Режимы отладки в URL** (только для QA): `?autostart`, `?spawn=N`, `?time=N`, `?boss=1`,
  `?levelup=1`, `?pause=1`, `?die=1`, `?result=1`, `?quality=low|high`, `?renderer=canvas`.

## Сборка и запуск

```bash
npm install          # phaser 4.2.1, esbuild, ws, playwright-core (dev)
npm run build        # → dist/index.html (один файл, офлайн); копия в release/LAMPLIGHT.html
npm run art          # PNG-листы спрайтов в qa/art/
npm run serve        # локальный сервер dist/ (или просто откройте dist/index.html)
```

## QA-процесс этого билда

1. Smoke-тесты API Phaser 4.2.1 в headless Chromium (WebGL2/SwiftShader): filters, lights,
   particles, arcade, RenderTexture, tint-modes — всё проверено живьём до написания gameplay-кода.
2. Визуальное ревью каждого спрайт-листа и тайлсета по PNG.
3. Headless-прогоны состояний (меню, бой, босс, драфт, пауза, финалы) со скриншотами в `qa/shots/`.
4. Найденные и исправленные баги релиз-качества: `RandomDataGenerator.real()` в Phaser 4 возвращает
   `[0, 2^32)` (заменено на `frac()`), совпадение окон стриминга чанков, `Image.play()`,
   геттер `phase` у босса, пул-менеджмент HUD/FX, лимиты FX/лута при масс-киллах.
